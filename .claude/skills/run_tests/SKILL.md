# Запуск тестов

1. Проверь, что Postgres и Redpanda подняты: `docker compose ps`
2. Если не подняты — выполни `docker compose up -d` и подожди 5 секунд
3. Запусти тесты: `pytest -v`
4. Если есть падения — проверь, не относится ли ошибка к состоянию БД (напоминание: тесты используют rollback, БД не должна "пухнуть" от старых прогонов)
